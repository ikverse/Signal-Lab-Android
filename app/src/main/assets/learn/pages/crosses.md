# Crosses above and is above

> **In short:** "Crosses above" is true only on the candle where something moves from under to over. "Is above" is true on every candle while it stays over.

The difference decides how often an idea matches.

## Is above

"The price is above the 200-candle average" is true on every candle while the price stays higher. It describes a state. It is good for a condition that has to hold alongside another one.

## Crosses above

"RSI crosses above 30" is true only on the single candle where RSI moves from 30 or lower to higher than 30. It describes a moment. It is good for the event that starts a signal.

## How the lab uses them

A signal is the first candle on which every condition holds. An idea usually has one moment (a cross) and one or two states (is above, is below). Using only states makes an idea match on a very long run of candles, which the lab counts as one signal at the start of the run.
